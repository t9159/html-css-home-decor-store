# HTML-CSS-HOME-DECOR-STORE

> **Final Project:** A responsive frontend interface for a Home Decor store, built with HTML5 and CSS3.

## About the Project
This project features a decorative and user-friendly website designed for a home styling and decor store. The website allows visitors to navigate through various product categories, learn about the brand, locate physical branches, and contact customer service.

## Key Features
- **Diverse Product Catalog:** An organized visual display of home decor items divided into categories: Lighting, Plants, Curtains, and Mirrors.
- **Content Pages:** "About" and "Home" pages presenting the store's brand identity and aesthetic.
- **Store Locator (Branches):** A dedicated page containing a detailed table of branch locations, including addresses, weekday opening hours, and contact details (phone and email).
- **Contact Us:** A dedicated page featuring an online form for users to leave their personal details and inquiries.
- **Main Navigation Menu:** A top navigation bar providing easy access to all site pages, including a dropdown menu for direct access to specific product categories.

## Technologies Used
- **HTML5** - For semantic structure and content.
- **CSS3** - For custom styling, layout, and responsive design.
